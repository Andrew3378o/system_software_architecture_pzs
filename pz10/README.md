
# Завдання 10.14 (індивідуальне)
Напишіть дві програми: одна просто виводить повідомлення, інша — викликає її після `fork()` за допомогою `exec()`.

## Теорія та технічна реалізація
У UNIX-подібних системах створення нових процесів розбито на два етапи. Спочатку викликається `fork()`, що створює точну копію поточного (батьківського) процесу. Далі в дочірньому процесі (`pid == 0`) за допомогою сімейства функцій `exec()` (зокрема `execl()`) виконується заміна поточного образу програми на новий виконуваний файл. Батьківський процес у цей час використовує системний виклик `wait(NULL)`, щоб призупинити своє виконання та дочекатися коректного завершення дочірнього процесу, уникаючи появи "процесів-зомбі".

## Приклад використання та демонстрація
Компіляція: `gcc message.c -o message та gcc caller.c`

Запуск: `./a.out`

Очікуваний вивід:
```
[caller.c] Батьківський процес (PID: 305825) починає роботу.
[caller.c] Батьківський процес чекає на завершення дочірнього...
[caller.c] Дочірній процес (PID: 305826) готується виконати exec()...
[message.c] Привіт! Я - друга програма, яку щойно викликали через exec().
[caller.c] Дочірній процес завершився. Головна програма закінчує роботу.
```
