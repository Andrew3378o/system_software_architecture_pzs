
## Завдання 3.5
Напишіть програму для копіювання одного іменованого файлу в інший. Імена файлів передаються у вигляді аргументів. Програма має:
- перевіряти, чи передано два аргументи, інакше виводити "Program need two arguments";
- перевіряти доступність першого файлу для читання, інакше виводити "Cannot open file .... for reading";
- перевіряти доступність другого файлу для запису, інакше виводити "Cannot open file .... for writing";
- обробляти ситуацію перевищення обмеження на розмір файлу.


## Технічна реалізація

Технічна реалізація програми базується на використанні стандартних потокових функцій бібліотеки `stdio.h` для поблочного перенесення даних. Програма використовує статичний буфер `char buffer[BUFFER_SIZE]` розміром 4096 байт для оптимізації операцій читання та запису. Процес копіювання організовано через цикл `while`, який зчитує дані за допомогою `fread` і одразу намагається записати їх у цільовий файл через `fwrite`. Важливою особливістю коду є перевірка результату виконання `fwrite`: якщо кількість фактично записаних байтів не збігається з кількістю прочитаних, програма ідентифікує це як помилку запису, що може бути спричинено досягненням системного ліміту `RLIMIT_FSIZE`. У такому випадку програма виводить повідомлення про перевищення ліміту або помилку запису, після чого коректно закриває обидва файлові дескриптори за допомогою `fclose`, запобігаючи витоку ресурсів. Також реалізовано перевірки на коректність аргументів командного рядка та успішність відкриття файлів у режимах `rb` та `wb`.

## Приклад використання програми

Для компіляції програми необхідно скористатися командою `gcc task3-5.c -o task3-5`, що створить виконуваний файл. Запуск програми здійснюється передачею двох шляхів до файлів, наприклад `./task3-5 src.txt dst.txt`. У разі успішного копіювання без виникнення системних помилок програма завершиться тихо. 

Для демонстрації обробки ліміту `max file size` можна скористатися командою `ulimit -f 1`, яка обмежить розмір файлів, що створюються, до 1 КБ. 

Якщо вхідний файл перевищує цей розмір, операційна система надішле процесу сигнал, і програма виведе повідомлення `File size limit exceeded or write error`. Приклад виводу:
```
andrew3378o@DESKTOP-N1R2BIO:/mnt/d/АСПЗ/pz3$ ./task3-5 src.txt dst.txt
File size limit exceeded (core dumped)
```
